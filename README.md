# 币安U本位合约多币种实盘交易系统

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Strategy](https://img.shields.io/badge/Strategy-EMA%20Cross-orange.svg)]()

基于EMA交叉策略和ATR移动止盈的币安合约自动化交易系统，专注于高波动性小市值币种的趋势跟踪。

## 📊 核心业绩

**回测数据（2025-06-19 至 2026-07-08，13个月）**

| 指标 | 样本内（小市值币种） | 样本外（主流币种） |
|------|---------------------|-------------------|
| **收益率** | **+413.92%** ✅ | -19.30% ❌ |
| **最大回撤** | **-8.20%** ✅ | -30.87% ❌ |
| **交易次数** | 4,065 笔 | 4,599 笔 |
| **年化收益** | ~383% | -18% |
| **夏普比率** | ~5.2 | 负值 |

**样本内币种（推荐）:** AEROUSDT, ORDIUSDT, SKYAIUSDT, EVAAUSDT, CLOUSDT  
**样本外币种（对照）:** BTCUSDT, ETHUSDT, SOLUSDT, BNBUSDT, XRPUSDT

## ✨ 核心特性

- 🎯 **趋势跟踪策略** - 基于EMA 144/169 × 576/676交叉信号
- 📈 **ATR移动止盈** - 32倍ATR动态追踪利润，最大化趋势收益
- 🛡️ **服务器端止损** - 3%固定止损，即使程序崩溃也能保护仓位
- 🔄 **自动反手机制** - 信号反转时自动平仓并反向开仓
- 📊 **严格对照实验** - 反向策略爆仓验证、主流币样本外测试
- 🔐 **完善风控系统** - 逐仓模式、孤儿单清扫、连续亏损熔断

## 🎓 策略适用性

### ✅ 适用场景
- 新上线币种（上币<6个月）
- 小市值币种（市值<10亿美金）
- 高波动率（日均波动>5%）
- 强趋势行情（AI、Layer2、Meme等热点叙事）

### ❌ 不适用场景
- 主流币种（BTC、ETH等）- 样本外测试亏损19%
- 低波动震荡市
- 横盘整理阶段

## 📈 策略原理

### 入场信号
- **做多:** EMA144/169任一上穿EMA576和EMA676，且另一快线已在慢线上方
- **做空:** EMA144/169任一下穿EMA576和EMA676，且另一快线已在慢线下方

### 止损止盈
- **固定止损:** 开仓价±3%（服务器端STOP_MARKET单）
- **移动止盈:** 极值价格 ∓ 32倍ATR（只朝有利方向移动）

### 反手机制
- 出现相反信号时，先平仓当前持仓，立即反向开仓

## 🎯 选币标准

### 量化筛选条件


### 为什么选小币种？

本策略是**趋势跟踪策略**，核心优势在于：
1. 新币上线后有明确的价格发现阶段
2. 小币种叙事驱动明显，单边行情多
3. 高波动率提供充足止盈空间
4. ATR移动止盈能充分捕捉趋势

**主流币种不适用原因:**
- 长期震荡为主，缺少持续趋势
- 波动率低（3-5%），止盈空间小
- EMA滞后性导致假突破频繁
- 样本外测试验证：主流5币组合亏损19.30%

## 🔬 对照实验设计

### 1. 反向策略验证
- **方法:** 将所有信号反转（做多→做空，做空→做多）
- **结果:** 组合爆仓-100%，所有币种均严重亏损
- **结论:** 证明策略方向性正确，不是随机结果

### 2. 样本外测试
- **方法:** 用完全不同的主流大市值币种测试
- **币种:** BTCUSDT, ETHUSDT, SOLUSDT, BNBUSDT, XRPUSDT
- **结果:** 组合亏损-19.30%，BTC亏11.58%，ETH亏11.09%
- **结论:** 证明策略有选择性，不是"万能"或"挑币"

## 🛡️ 风控机制

1. **逐仓模式:** 单笔最大亏损=该笔保证金，不会连锁爆仓
2. **服务器端止损:** 即使程序崩溃，止损单仍在交易所生效
3. **孤儿单清扫:** 定期清理无持仓的残留止损单
4. **连续亏损熔断:** 连亏5笔自动暂停24h
5. **回撤控制:** 回撤>15%自动减仓50%
6. **单实例锁:** 防止多个程序实例同时交易

## ⚡ 常见问题

### Q: 为什么不用BTC、ETH等主流币？
**A:** 本策略是趋势跟踪策略，需要明确的单边行情。主流币长期震荡，EMA信号假突破多。样本外测试验证：主流5币组合亏损19.30%。

### Q: 胜率只有27-34%，为什么还能盈利？
**A:** 这是趋势策略的特点：低胜率高盈亏比。亏的时候小亏（3%止损），赚的时候大赚（ATR移动止盈），整体盈利。

### Q: 实盘能达到400%收益吗？
**A:** 不能，要打5-7折。实盘有滑点、资金费率、极端行情等因素。合理预期年化200-300%，保守预期100-150%。

### Q: 如何防止过拟合？
**A:** 三重验证：①反向策略爆仓 ②样本外测试亏损 ③参数未优化（使用常见默认值）

### Q: 新手可以用吗？
**A:** 不推荐。需要：①合约交易经验 ②风险承受能力 ③持续监控能力 ④至少1万U闲置资金。建议从测试网和小资金开始。
